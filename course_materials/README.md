# Course Materials

Drop your Blackboard course materials here (PDFs, slides, notes, assignment descriptions).

Once files are here, Claude can help you:
- Summarize lectures and readings
- Create study guides and flashcards
- Explain difficult concepts
- Help with assignments and problem sets
- Generate practice questions

## Folder Structure

Organize by course:
```
course_materials/
├── COURSE_101/
│   ├── lecture_01.pdf
│   ├── assignment_01.pdf
│   └── notes.txt
├── COURSE_201/
│   └── ...
```
